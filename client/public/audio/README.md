# FocusLock ambient audio

`rain.wav`, `cafe.wav`, and `white-noise.wav` are short original procedural samples generated for this project. They are static local assets used by the Study Sounds controls; no audio is streamed or sent to the server.

Replace these samples only with audio you created or have permission to use. If you change the file formats or names, update the sound list in `client/src/components/AudioControls.jsx`.
